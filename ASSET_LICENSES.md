## Rule for future free assets

Before any external asset is committed, add a row recording the package name, author, source URL, exact license, files used and modifications. Prefer CC0/public-domain material or licenses that clearly permit use in a game. An interesting forum/resource link is not by itself license evidence; the original asset page/license must be checked.
